# 👤 Personal Profile Card

A simple and responsive **Personal Profile Card** created using HTML, CSS, and JavaScript. The project displays personal information in a clean card-based design with interactive hover effects and mobile responsiveness.

## ✨ Features

* 👤 Profile photo
* 📝 Name and designation
* 🔗 Social media links
* 🎨 Clean and modern UI
* ✨ Hover effects and animations
* 📱 Responsive design for mobile devices
* 💻 Built using only HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling, responsiveness, and hover effects
* **JavaScript** – Interactions

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/yourusername/personal-profile-card.git
```

2. Open the project folder.
3. Run `index.html` in your browser.

You can also use **VS Code Live Server** to run the project.
